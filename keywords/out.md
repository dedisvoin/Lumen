# out
---

Выводит значение без перевода строки. Полезно для пошагового вывода.
```lumen
out "x = ";
out x;
out "\n";
```

Вывод `out` появляется только в **скомпилированной** программе (`-c` / `-build`).
В режиме интерпретатора (`-r`) `out` ничего не печатает — для вывода при
пошаговом запуске используйте `echo`.
