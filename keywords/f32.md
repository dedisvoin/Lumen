# f32
---

Число с плавающей точкой, 32 бита (single-precision).

Дробные литералы имеют тип `f64`, поэтому тип `f32` достигается либо аннотацией (сужение), либо оператором `as`:
```lumen
let a: f32 = 1.5;      // 1.5 f32 (сужение при объявлении)
let b = 1.5 as f32;    // 1.5 f32
echo typeof(b);        // f32
```

Аннотированная переменная с `typeof` подтверждает тип:
```lumen
strict let c: f32 = 3.14 as f32;   echo c;   echo typeof(c);  // 3.14 f32
```

Точность: числа хранятся в 32-битном формате; печатаются как `f64`-литералы значения:
```lumen
echo 0.1 as f32 + 0.2 as f32;      // ~0.300000 (f32, но выводится со своего типа)
```
