# const
---

Модификатор неизменяемости.

После инициализации переменная не может быть изменена — присваивание выдаст ошибку `CONST_REASSIGNED`.

Применяется в трех конструкцияx:
`const let` — декларация константной переменной
`new <const> ...` — выделение константной ячейки
`const fn ...` — объявление константной функции
```lumen
const let max = 100;
// max = 200; // ошибка: CONST_REASSIGNED

////////////////////////////////////////////////

let p = new <const> 3.14;
*p = 2.71; // ошибка: CONST_REASSIGNED

////////////////////////////////////////////////

const fn add(a, b) : {
    ret a + b;
}
let add = 10; // ошибка: CONST_REASSIGNED
```
