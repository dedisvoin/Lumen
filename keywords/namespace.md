# namespace
---

Группирует код (функции, переменные, типы) в именованное пространство имён.

Доступ к членам — через `::`: `Math::sq`. Пространства могут вкладываться.
```lumen
namespace Math {
    fn sq(v: i32) -> i32 : { ret v * v; }
    let PI = 3.14;
}

let s = Math::sq(2);
let pi = Math::PI;
```
