# auto
---

Специальный тип времени выполнения, позволяющий из выражения автоматически выводить тип.

Используется в трех случаях:

1. Автоматический вывод типа для `strict` переменной
2. Автоматический вывод типа ячейки для конструкции `new <strict(auto) ...`
3. Вывод типа переменой при декларации inline хинтом
```lumen
let v: auto = 10;   // увидим inline хинт i64
```
---
```lumen
strict let v: auto = 10;   // автоматически выводим тип (i64)
v = 3.14;   // ошибка
```
---
```lumen
let pointer = new <strict(auto)> 10;   // автоматически выводим тип (i64)
echo typeof(pointer); // *(i64)
```
