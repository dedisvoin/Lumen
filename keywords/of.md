# of
---

Ключевое слово формы перебора в цикле `for-each`:
`for (<декларация>; of <выражение>;) { ... }`.

Разделяет декларацию переменной-элемента и контейнер, по которому идёт перебор.
```lumen
let arr = Array[i64, 3]{10, 20, 30};
for (let x; of arr;) {
    echo x;
}
```

`of` — зарезервированное слово: его нельзя использовать как имя переменной,
функции или поля структуры.

## Перебор пользовательских типов: `__of__`

Если контейнер — не массив/кортеж/строка, а объект вашей структуры, можно задать
источник итерации через метод-оператор `__of__`. Он вызывается один раз перед
циклом и должен вернуть контейнер (обычно `-> ref Array[T]`), по которому идёт
перебор:

```lumen
struct[T] Vector {
    strict let _box: Array[T];

    fn __of__(ref self) -> ref Array[T] : {
        ret self._box;
    }
}

let a = Vector[i64]{_box: {1, 2, 3}};
for (let n; of a;) {
    echo n;            // 1, 2, 3
}
```

Если `__of__` возвращает `ref` на поле (как выше), то `for (ref let x; of a;)`
даёт живой алиас на элементы и записывает их обратно в поле-контейнер:

```lumen
for (ref let x; of a;) {
    x = x * 10;        // a._box меняется
}
```
