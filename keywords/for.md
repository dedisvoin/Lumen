# for
---

Цикл. Поддерживает две формы: C-стиль и перебор элементов (`for-each`).

## C-стиль

`for (инициализация; условие; шаг) { ... }`.

- инициализация — оператор (например, `strict let i: auto = 0`);
- условие проверяется перед каждой итерацией;
- шаг выполняется в конце итерации;
- внутри доступны `break` и `continue`.
```lumen
for (strict let i: auto = 0; i < 10; i = i + 1) {
    echo i;
}
```

## for-each

`for (<декларация>; of <выражение>;) { ... }` — перебор элементов массива,
кортежа или строки.

- `<декларация>` — `let x`, `let x: T` или `ref let x`;
- `<выражение>` — контейнер (массив, кортеж или строка);
- обычная `let` даёт **копию** элемента;
- `ref let` даёт **живой алиас** на элемент — запись в него меняет сам контейнер;
- `<выражение>` вычисляется один раз, до входа в цикл;
- внутри доступны `break` и `continue`.

```lumen
let arr = Array[i64, 3]{10, 20, 30};

// копия: sum == 60
let sum = 0;
for (let x; of arr;) {
    sum += x;
}

// ссылка: элементы массива увеличиваются на 1
for (ref let e; of arr;) {
    e = e + 1;
}
```

По строке перебираются символы (`char`):

```lumen
for (let ch; of "abc";) {
    echo ch;   // a, b, c
}
```

`ref let` применим только к массивам и кортежам (живой алиас на элемент
строки невозможен — используйте обычную `let`).

## Перебор пользовательского типа

Если `<выражение>` — объект структуры, перебор идёт по контейнеру, который
возвращает метод-оператор `__of__`:

```lumen
struct[T] Vector {
    strict let _box: Array[T];
    fn __of__(ref self) -> ref Array[T] : { ret self._box; }
}
let v = Vector[i64]{_box: {1, 2, 3}};
for (let n; of v;) { echo n; }        // 1, 2, 3
for (ref let x; of v;) { x = x * 2; } // write-back в v._box
```
