# for
---

Цикл в C-стиле: `for (инициализация; условие; шаг) { ... }`.

- инициализация — оператор (например, `strict let i: auto = 0`);
- условие проверяется перед каждой итерацией;
- шаг выполняется в конце итерации;
- внутри доступны `break` и `continue`.
```lumen
for (strict let i: auto = 0; i < 10; i = i + 1) {
    echo i;
}
```
