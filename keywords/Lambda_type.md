# Lambda
---

Тип анонимной функции (замыкания). Возвращается при создании `lambda { ... }`.

Хранит лямбду и её окружение; вызов сохранённой лямбды в рантайме пока не поддерживается (будет ошибка). Тип самого выражения:
```lumen
let l = lambda(v: i64) -> i64 : { v * 2 };
echo typeof(l);                       // Lambda
```
Если нужна вызываемая функция-значение — используйте `fn` + `Func`:
```lumen
fn dbl(v: i64) -> i64 : { ret v * 2; }
let f: Func = dbl;
echo f(4);                            // 8
```
