# strict
---

Модификатор переменной / объявления типа с проверкой «точного» соответствия типа на этапе компиляции.
Переменная со `strict` не может быть переприсвоена значением другого типа (например, `strict i64` не примет `i32`).

Проверка касается и значений литералов: целочисленный литерал имеет тип `i64`, поэтому для получения строгого `i32` нужен явный `as`:
```lumen
strict let n = 10;       // i64 — ок, литерал i64
strict let m: i32 = 10;  // ошибка: ожидался i32, но литерал i64
strict let m2: i32 = 10 as i32;  // ок
```

For values in cells:
```lumen
let c = new <strict(i64)> 5;   echo *c;      // 5
let c2 = new <strict(i32)> (1 as i32);  echo *c2;  // 1
```
`strict i32 = new <strict(i32)> 1` — ошибка (литерал — `i64`).

Для `let` без `strict` аннотация допускает сужение (см. `let x: i32`).
