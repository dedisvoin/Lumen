# ref
---

**ref** создаёт живой алиас на l-значение: все обращения к имени идут к цели.
```lumen
let g = 10;
ref let r = g;      // r — алиас g
r = 100;            // теперь g == 100
```

ref-параметры функций пишут обратно в переданную переменную:
---
```lumen
fn inc(ref x: i64) : { x = x + 1; }
let a = 5;
inc(a);             // a == 6
```

ref-функции возвращают живую ссылку (`-> ref T`), ей можно присваивать:
---
```lumen
fn get() -> ref i64 : { ret g; }
get() = 42;         // g == 42
```

ref нельзя комбинировать с `static`/`private`/`final` и объявлять без инициализации.
