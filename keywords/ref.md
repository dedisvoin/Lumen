# ref
---

**ref** создаёт живой алиас на l-значение: все обращения к имени идут к цели.
```lumen
let g = 10;
ref let r = g;      // r — алиас g
r = 100;            // теперь g == 100
```

ref-параметры функций пишут обратно в переданную переменную:
---
```lumen
fn inc(ref x: i64) : { x = x + 1; }
let a = 5;
inc(a);             // a == 6
```

ref-функции возвращают живую ссылку (`-> ref T`), ей можно присваивать:
---
```lumen
fn get() -> ref i64 : { ret g; }
get() = 42;         // g == 42
```

ref нельзя комбинировать с `static`/`private`/`final` и объявлять без инициализации.

## const-корректность

Ссылка на `const`-ячейку допустима только если сама ссылка объявлена `const`:
запись через неё обошла бы неизменяемость источника.
```lumen
const let a = 0;
const ref let b = a;   // ok: b — ссылка только для чтения
b = 5;                 // ошибка: b объявлена const
```
`const ref` можно навесить и на изменяемую цель — получится представление
только для чтения, отражающее изменения цели:
```lumen
let m = 10;
const ref let r = m;   // r показывает текущее значение m
m = 20;
echo r;                // 20
```
`ref let b = a;` на `const`-цель — ошибка (`ref-variable must reference an l-value`).
