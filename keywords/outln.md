# outln
---

Выводит значение с переводом строки (аналог `echo`). Полезно для логов.
```lumen
outln "line";
outln "value: " + v;
```

Вывод `outln` появляется только в **скомпилированной** программе (`-c` / `-build`).
В режиме интерпретатора (`-r`) `outln` ничего не печатает — для вывода при
пошаговом запуске используйте `echo`.
