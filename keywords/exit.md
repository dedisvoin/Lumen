# exit
---

Немедленно завершает программу с указанным кодом возврата. Строгая форма — утверждение-оператор со
**обязательными** выражением кода и завершающей точкой с запятой:
```lumen
exit 0;          // код 0
exit code_var;   // код из переменной/выражения
exit 1+2;        // любое целое выражение
```
`;` после `exit <expr>` обязателен (`exit 3` без `;` или голый `exit` — ошибка парсера).

Поведение по фазам:
- **интерпретатор (`-r`)**: `exit` останавливает выполнение — операторы после него не
  исполняются, процесс возвращает указанный код возврата;
- **транспиляция (`-build`)**: генерирует `::exit((int)rt::num(...))` — завершение
  реального процесса;
- **deep-анализ (lint/LSP)**: выражение кода проверяется, но `exit` **не исполняется** —
  анализ не прерывается и компилятор/сервер не падают.

Требования:
- код возврата — целое (`i8`..`i64`); иначе ошибка `error[128]` (`exit 3.5;`
  не соберётся);
- `exit` разрешён на любом уровне: глобально, в функции, в цикле, в `if`;
- до `exit` включён в проверки «потока» (бесконечный `while(1) { exit 0; }` не
  считается бесконечным циклом).

```lumen
if (error) {
    exit(1);
    // дальше не выполняется
}
```
