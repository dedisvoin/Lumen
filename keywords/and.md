# and
---

Логическое «И» (короткое замыкание). В языке используется **символьная** форма `&&` (форма `and` зарезервирована, но синтаксически оператор — `&&`).

Возвращает `true`, только если **оба** операнда истинны.
```lumen
let ok = a > 0 && b > 0;
if (a > 0 && b > 0) {
    echo "оба положительные";
}
```

Работает при коротком замыкании — вторая часть не вычисляется, если первая ложна:
```lumen
let x = 10;
if (x != 0 && 20 / x > 0) { ret "ok"; }
```
