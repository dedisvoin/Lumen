# is
---
Проверка, что значение имеет ровно указанный тип. Зарезервированное слово; в текущей версии проверку делают через `typeof() == Тип`.
```lumen
let x = 5;
echo typeof(x) == i64;   // true
echo typeof(x) == i32;   // false
```

Инфиксный `x is Тип` как оператор пока не реализован — используйте сравнение с
`typeof`/`typeis`:
```lumen
let v: any = 3.14;
if (typeof(v) == f64) { echo "число"; }   // по рантайм-типу
```

# typeis
---

`typeis(x)` возвращает **статический (объявленный) тип** выражения как `Type`
(реализован). `typeof(x)` возвращает рантайм-тип значения. Сравнение со типом даёт
проверку «имеет ровно указанный тип»:
```lumen
let x = 5;
echo typeof(x) == i32;   // false (значение i64)
echo typeis(x) == i64;   // true  (объявлен как i64)
```
Различие на union-типах:
```lumen
let a: i64|f64 = 5;
echo typeof(a) == i64;            // true  (значение сейчас i64)
echo typeis(a) == (i64|f64);      // true  (объявленный тип)
```
Для значений с динамическим типом `any`:
```lumen
let v: any = "str";
echo typeof(v) == str;   // true
```
