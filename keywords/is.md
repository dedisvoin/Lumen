# is
---
Проверка, что значение имеет ровно указанный тип. Зарезервированное слово; в текущей версии проверку делают через `typeof() == Тип`.
```lumen
let x = 5;
echo typeof(x) == i64;   // true
echo typeof(x) == i32;   // false
```

`typeis(x, Тип)` и инфиксный `x is Тип` как операторы пока не реализованы — используйте форму с `typeof`:
```lumen
let v: any = 3.14;
if (typeof(v) == f64) { echo "число"; }
```

# typeis
---

Проверка, что значение принадлежит указанному типу. Зарезервированное слово; операторная форма `typeis(x, i32)` пока не реализована. Используйте `typeof(x) == i32`:
```lumen
let x = 5;
echo typeof(x) == i32;   // true
if (typeof(x) == i64) {
    echo "это i64";
}
```
Для значений с динамическим типом `any`:
```lumen
let v: any = "str";
echo typeof(v) == str;   // true
```
