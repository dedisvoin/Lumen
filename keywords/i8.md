# i8
---

Целое число со знаком, 8 бит. Диапазон: `-128..127`.

Все целочисленные литералы имеют тип `i64`, поэтому для получения `i8` нужен инфиксный оператор `as`:
```lumen
let a = 5 as i8;
echo typeof(a);             // i8
echo sizeof(1 as i8);       // 1
```

Выход за диапазон — «обёртка» по модулю 256:
```lumen
let wrapped = 300 as i8;
echo wrapped;               // 44  (300 − 256 = 44)
echo 128 as i8;             // -128 (128 − 256)
```

Тип указывается при декларации:
```lumen
strict let byte: i8 = 5 as i8;
echo byte;                  // 5
```
