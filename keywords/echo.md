# echo
---

Выводит значение в консоль с переводом строки. Принимает выражения разных типов (числа, строки, char, bool).
```lumen
echo "hello";
echo x;
echo "sum = " + x;
```

`echo` — единственная форма вывода, которая работает **в обоих режимах**: и в
интерпретаторе (`-r`), и в скомпилированной программе (`-c` / `-build`). `out` и
`outln` выводят только после компиляции.
