# sizeof
---

Возвращает **число элементов** (длину) значения. Работает **только со значениями**, не с типами:

- массив `Array[i64]` → число элементов;
- кортеж `Tuple[...]` → число элементов;
- строка `str` → число символов;
- символ `char` → 1 (или `__sizeof__(char)`).

Тип передавать нельзя: `sizeof(i64)` — **ошибка** (для этого есть `typeof`).
```lumen
let arr = {10, 20, 30};
echo sizeof(arr);              // 3

let tpl = !{1, "a", true};     // кортеж (литерал !{...})
echo sizeof(tpl);              // 3

echo sizeof("hello");          // 5 — число символов
echo sizeof('x');              // 1
```

В условии — часто с `sizeof(массив) > 0`:
```lumen
let nums = {1, 2, 3};
if (sizeof(nums) > 2) { echo "много"; }
```
