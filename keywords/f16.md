# f16
---

Число с плавающей точкой 16 бит (IEEE-754 half, `binary16`). Реализовано: входит в `Float` и `Numeric`, участвует в выводах типов, кастах и арифметике.

Литералы без суффикса имеют тип `f64`, поэтому значение `f16` создаётся только через `as f16`:
```lumen
let a = 0.5 as f16;        echo typeof(a);   // f16
let b = 3.14159265 as f16; echo b;            // 3.140625 (half)
```

Хранение и точность:
- значение хранится как 16-битные биты binary16 (5 бит экспонента, 10 бит мантисса);
- конверсия из/в double с округлением round-to-nearest-even;
- макс. конечное число 65504; переполнение даёт `inf` (напр. `100000.0 as f16`);
- ранг `f16 < f32 < f64`: `f16 + i64` → `f16`, `f16 + f64` → `f64`;
- `strict let x: f16 = ...` требует точного типа (f16-значения можно получить только через `as f16`), не-strict аннотация значение не меняет.
