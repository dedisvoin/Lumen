# fn
---

Объявляет функцию.
Параметры аргументов указываются через `:` , возвращаемый тип — после `->`.

Generic функции:

Generic функци создаются при помощи специального синтаксиса `fn <name>[ generic_args, ... ]( args, ... ) -> type_expr : { body }`
```lumen
fn add(a: i32, b: i32) -> i32 : {
    ret a + b;
}

let s = add(1, 2);
```
---
```lumen
// шаблонная функция
fn add[T: Type](a: T, b: T) -> T : {
    ret a + b;
}
```
