# input
---

Читает строку из стандартного ввода и возвращает её как `str`.

Необязательная подсказка-сообщение (только `str` или `char`) выводится перед
чтением. При глубоком анализе на каждый `input()` выдаётся предупреждение
(значение статически подставляется как `''` — реальное значение известно
только в рантайме). Неверный тип подсказки — ошибка.
```lumen
let name = input("Ваше имя: ");
echo "Привет, " + name + "!";

let line = input('>');         // char-подсказка тоже допустима
let raw  = input();            // без подсказки — то же предупреждение
```
