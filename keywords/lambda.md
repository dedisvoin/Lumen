# lambda
---

Создаёт анонимную функцию (замыкание). Синтаксис аналогичен `fn`, но без имени.

Лямбда может быть сохранена в переменную; **вызов сохранённой лямбды в рантайме пока не поддерживается** (ошибка «Call attempted on a value of type 'Null'»). Для передаваемой функции-значения используйте обычную `fn` и тип `Func`.
```lumen
let double = lambda(v: i64) -> i64 : { v * 2 };
echo typeof(double);                  // Lambda (тип).
```
Для вызываемых значений применяйте `fn`:
```lumen
fn twice(v: i64) -> i64 : { ret v * 2; }
let f: Func = twiceork;
echo f(2);                            // 4
```
