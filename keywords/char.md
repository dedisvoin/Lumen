# char
---

Один символ Unicode (одна кодовая точка). Записывается в одинарных кавычках. Тип `char`.
Поддерживаются любые символы, в том числе многобайтовые в UTF-8 — символ хранится
целиком, без обрезания:
```lumen
let c: char = 'A';
let ya: char = 'я';   // 2 байта в UTF-8 — хранится полностью
let zh: char = '中';   // 3 байта
let em: char = '🙂';   // 4 байта
```

Приведение к коду символа (кодовая точка Unicode) и обратно:
```lumen
echo 'A' as i64;      // 65
echo 'я' as i64;      // 1103 (U+044F)
echo 1071 as char;    // 'я'
let code = 'A' as i64;
echo (code + 1) as char;   // 'B'
```

Сравнение символов и доступ к элементу строки (индексация строки идёт по
кодовым точкам, а не по байтам):
```lumen
let s = "hello";
let first = s[0];          // 'h'
echo first == 'h';         // true

let w = "привет";
echo sizeof(w);            // 6 — число символов
echo w[1];                 // 'р'
```

Пустой код и пробел:
```lumen
echo ' ' as i64;           // 32
```

Литерал в одинарных кавычках обязан содержать ровно один символ (одну кодовую
точку). Если внутри `''` не один символ (`''`, `'ab'`), выдаётся предупреждение
`warning[206]`, а литерал трактуется как строка (`str`):
```lumen
let a = 'ab';       // warning[206]: char literal length: 2 -> type str
let b = '';         // warning[206]: char literal length: 0 -> type str
let c = 'a';        // type char
```
