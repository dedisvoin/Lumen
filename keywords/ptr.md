# ptr
---

Указатель на данные (тип `*(T)`). Способы получения:

- `ptr(addr, Type)` — создать указатель заданного типа на произвольный адрес;
- `new` — выделение ячейки;
- `&x` — взятие адреса переменной (получение указателя).

Поддерживает разыменование `*p`, сравнение указателей, адресную арифметику `ptr + n`, `ptr - ptr`.
```lumen
let p = ptr(0x1000, i64);  // *i64, адрес 0x1000
let v = *new 0;            // значение ячейки
let q = p + 1;             // соседняя ячейка (адрес +1)
```
