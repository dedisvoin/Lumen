# eval
---

Блок, содержимое которого **вычисляется на этапе анализа** (compile-time), а не
только во время работы программы. Значения `let`/`const` внутри «замораживаются»
и доступны после блока как глобальные compile-time-константы.

Тело записывается либо блоком `{ ... }`, либо одиночным стейтментом:
`eval let x = 2 + 2;`. Обе формы равнозначны.

Блок разрешён **только на верхнем уровне** (в глобальной области). Внутри функции,
условия, цикла или другого блока он запрещён — ошибка `EVAL_NOT_TOP_LEVEL` (128).
Вложенные `eval` запрещены тем же правилом.

```lumen
eval {
    let table = buildTable();   // buildTable() выполняется на этапе анализа
    let n = table.size();
    echo "n =", n;              // вывод перехватывается → инлайн-хинт редактора
}

let first = table[0];           // table — compile-time-константа
```

Одиночный стейтмент пишется без фигурных скобок:

```lumen
eval let answer = 6 * 7;
outln(answer);                  // 42
```

Внутри блока разрешены `echo`/`out`/`outln`: их вывод **не** идёт в реальный
stdout, а перехватывается и показывается **инлайн-хинтами** в редакторе.

Запрещено (ошибка `EVAL_NOT_CONST`, 129): `input`, `extern fn`, `#cppinclude`,
любой I/O кроме `echo`/`out`/`outln`, а также указатели, утекающие из блока.

У каждого блока **свой бюджет итераций циклов**. При его исчерпании —
`EVAL_BUDGET_EXCEEDED` (130): блок не зависает, его незавершённые значения не
замораживаются.

См. также `typeof`, `mod`.
