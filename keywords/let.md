# let
---

Объявляет переменную.
поддерживает несколько модификаторов:

- `auto` — выводит тип автоматически;
- `strict` — строгая типизация;
- `const` — неизменяемая переменная;
- `private` — приватная переменная (доступна только внутри структуры или пространства имен).

Ключевые особенности:

Переменной выделяется адресованная ячейка в виртуальной памяти;
При создании статической переменной тип привязывается к ячейке;
```lumen
let x = 10;                 // i64 по умолчанию для целых чисел

strict let y: auto = 10;    // i64, строгая типизация c автоматическим выводом
strict let z: bool;         // bool, строгая типизация
const let pi = 3.14;        // неизменяемая f64
let name: auto = "hello";   // : auto позволяет увидеть inline тип
let a = new 0;              // *i64 (указатель)
```
