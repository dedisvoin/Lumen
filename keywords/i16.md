# i16
---

Целое число со знаком, 16 бит. Диапазон: `-32768..32767`.

Все целые литералы имеют тип `i64`, поэтому `i16` получают через `as`:
```lumen
let a = 5 as i16;      echo a;    echo typeof(a);   // 5 i16
```
Аннотация + сужение при объявлении (допустимо, т.к. литерал помещается):
```lumen
let b: i16 = 300;      echo b;    echo typeof(b);   // 300 i16
```

Выход за диапазон — «обёртка» по модулю 65536:
```lumen
echo 40000 as i16;      // -25536  (40000 − 65536)
echo 70000 as i16;      // 4464
```

Для строгой аннотации нужно точное соответствие:
```lumen
strict let c: i16 = -8 as i16;  echo c;   // -8 i16
```
