# assert
---

Проверяет условие во время выполнения; если оно ложно — выдаётся ошибка.

Синтаксис: `assert условие;` или `assert условие, сообщение;`.
Сообщение должно быть строкой (`str`) или символом (`char`) — любое другое
значение даёт ошибку.
```lumen
assert(x > 0, "x должен быть положительным");
assert x >= 0, 'в';
```
