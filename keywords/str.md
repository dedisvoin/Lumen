# str
---

Строка Unicode (UTF-8). Поддерживает:

- конкатенацию через `+`;
- доступ к символу по индексу `s[i]` → `char` (присваивание `s[i] = x` запрещено — `STRING_INDEX_IMMUTABLE`);
- сравнение `==`, `!=` (порядковые операторы `<`, `>`, `<=`, `>=` для строк
  не поддерживаются — `BINARY_COMPARE_INVALID_TYPE`).
```lumen
let s: str = "hello";
let c = s[0];       // 'h'
let t = s + "!";
```

Индексация и `sizeof` работают с **кодовыми точками** (символами Unicode), а не с
байтами, поэтому многобайтовые символы считаются за один:
```lumen
let w = "привет";
echo sizeof(w);     // 6
echo w[1];          // 'р'
```

Литерал в двойных кавычках — всегда `str`, независимо от длины. В частности
`"a"` имеет тип `str` (а не `char`); для одиночного символа используйте `'a'`.
