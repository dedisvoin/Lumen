# new
---

Оператор выделения ячейки в виртуальной памяти. Возвращает указатель (`*(T)`) на выделенную ячейку.

Модификаторы:
- `new const` — неизменяемая ячейка;
- `new <strict(тип)>` — ячейка со строгим типом значения.

Значения литералов по умолчанию `i64`, поэтому для строгой ячейки с узким типом нужно явное приведение:
```lumen
let a = new 0;             // *i64, ячейка со значением 0
let b = new <strict(i64)> 5;        // *i64
let c = new <strict(i32)> (1 as i32); // *i32
let v = *a;                // прочитать значение
```

`new <strict(i32)> 1` — ошибка (значение 1 — тип `i64`, а нужен `i32`).

Память освобождается через `del`.
