# as
---

**Инфиксный оператор** явного приведения к типу: `значение as Тип`. Сужение/расширение целых, char→i64, f64→i64 (отбрасывание дробной части).

`as` — именно инфикс; записи `as(value, тип)` не существует (это ошибка).
```lumen
let n = 10 as i32;             // i32
echo typeof(n);                // i32

let ch = 'A';
echo ch as i64;                // 65 (код символа)

let pi = 3.7;
echo pi as i64;                // 3 (дробная часть отбрасывается)

let narrow = 300 as i8;        // 44 (обёртка по модулю 256)
```

Приведение флоата к целому — отбрасывание (truncation), не округление:
```lumen
echo 2.9 as i64;               // 2
```
