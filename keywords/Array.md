# Array
---

Тип массива — однородная коллекция элементов одного типа.

Параметризуется типом в квадратных скобках: `Array[i64]`. Литерал — `{...}`;
индексация — `arr[i]`.
```lumen
let arr: Array[i64] = {1, 2, 3};
echo arr[0];                 // 1
```

Массив фиксированной длины — `Array[T, N]` и конструктор `Array[T, N]{...}`:
```lumen
let fixed = Array[i64, 3]{7, 8, 9};
strict let two: Array[i64, 2] = Array[i64, 2]{4, 5};
```

Целочисленные литералы всегда `i64`, поэтому для узкого типа элемента нужен
явный каст: `let a: Array[i32] = {1 as i32, 2 as i32};`.
