# if
---

Условный оператор. Выполняет блок, если условие истинно.

- Условие — логическое выражение (`bool`);
- поддерживает операторы `and`, `or`, сравнения `==`, `!=`, `<`, `<=`, `>`, `>=`;
- ветка `else` необязательна.
```lumen
if (x > 0) {
    echo "positive";
} else if (x < 0) {
    echo "negative";
} else {
    echo "zero";
}
```
