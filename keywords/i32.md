# i32
---

Целое число со знаком, 32 бита. Тип по умолчанию для целых не гарантирован — литералы имеют тип `i64`, поэтому сужение делается оператором `as` (инфиксная форма).
```lumen
let a = 1 as i32;
echo typeof(a);          // i32
```

Форма `as(5, i32)` (функция-каст) **не существует** — приведение всегда пишется как `значение as Тип`:
```lumen
let b = 5 as i32;        // 5
echo b;                  // 5
echo typeof(b);          // i32
```

Сужение с обёрткой при выходе за диапазон:
```lumen
echo (5_000_000_000 % 4_294_967_296) as i32;   // 705032704 (wrap-логика)
```
Аннотированная переменная (с нестрогим let):
```lumen
let c: i32 = 7;          // ок без сужения необходимости
echo c;                  // 7
```
